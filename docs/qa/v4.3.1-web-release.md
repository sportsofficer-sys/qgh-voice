# QGH Voice v4.3.1 — approved web update

5 September 2026. The user reviewed the local preview and explicitly approved publication to the existing public site: https://sportsofficer-sys.github.io/qgh-voice/.

## Scope

- Red acknowledgements above homing show the actual reported heading or requested range, and the commanded turn direction/target. Tactical readbacks include the addressed callsign. Returned data is captured when the command executes, before the visual transition; subsequent aircraft motion/selection cannot change that report.
- A separate red stopwatch sits at the right of the acknowledgement row. It mirrors the existing exercise clock: Start shows it, Stop freezes it, and Reset clears it. Clock ticks cannot overwrite command readbacks. Both manual and voice clock controls use the same existing event path.
- Normal QGH treats turns with or without the word "heading" as equivalent. Offline tactical grammars retain these paired phrases when shared-designator aliases need compaction. U/S Compass keeps timed turns and does not expose heading reports.
- Existing control highlights, confirmation gates, D/F transmission visibility, flight physics, random starts, formations and replay remain unchanged.

## Verification

- 95 Node tests passed, including the existing 10 Normal and 10 U/S randomized exercises.
- 12 browser readback flows passed in installed Edge: Single/Tactical × Normal/U/S at 1366×768, 360×800 and 412×915. Checks include collapsed single-aircraft controls, heading-phrase equivalence, actual report data, separate timer/readback geometry, Start/Stop/Reset, manual controls, no horizontal clipping and no runtime errors.
- `node scripts/verify-release-version.mjs`, `node scripts/build-web.mjs`, and `git diff --check` are release gates.
- Reproduce the focused browser checks with `node scripts/qa-voice-readback.cjs`; Playwright must be available and `QGH_QA_URL` may point at a local or deployed build. Screenshots remain ignored local artifacts under `artifacts/voice-readback/`.

Browser checks inject recognized transcripts. They verify execution and presentation, not live microphone recognition accuracy. No audio or transcripts are recorded or uploaded. Existing extreme four-aircraft maximum-length/shared-designator callsigns can still exceed the offline grammar byte budget and omit heading phrases; this pre-existing limit is not claimed fixed. Within an overloaded grammar, redundant heading-call aliases are compacted to a full spoken callsign; leading-zero suffixes retain digit spelling.
