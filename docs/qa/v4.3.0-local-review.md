## Improvements

- Desktop/tablet retain a separate movable DRAG/PTT/VOICE rail with reserved default space, viewport/safe-area clamping, saved position and Reset position.
- Portrait phones use a central PTT bottom dock. The page scrolls in a separate area above it; the dock cannot cover the exercise controls. Drag snaps to the top or bottom edge, with a separate phone position preference.
- PTT shows an immediate pressed state, only shows Listening after capture starts, and shows Processing after release. Outside release, interrupted capture, stale startup errors, keyboard focus loss and repeated calls have stronger guards.
- Heard changes to Applied beside the D/F display; actual command execution remains immediate. Confirmation-required and rejected calls never get an Applied receipt. Successful calls highlight the existing affected fields/buttons.
- LAST CALL in Voice settings shows the heard text, interpretation and result. It is held in page memory only, never persisted or transmitted. A single dedicated live region announces the final result.
- More legible offline setup/recovery guidance. No automatic download for a model absent from local storage. Manual controls remain usable without voice.
- Compact exercise headers, clearer tactical selection, larger touch targets, and grouped sticky review controls with selected speed/Zoom states and a short zoom hint.
