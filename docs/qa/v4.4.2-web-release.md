# v4.4.2 — Numeric Callsigns

Released: 6 September 2026

## Change

- Single Aircraft and Tactical QGH now accept standalone numeric callsigns from 100 to 999 alongside existing text callsigns.
- Offline voice routing accepts the written number and aviation digit-by-digit speech. For example, callsign `387` is addressed as “Tree Eight Seven.”
- An unknown numeric tactical callsign is rejected instead of being routed to the currently selected aircraft.

## Scope

The flight model, exercise workflow, controls, D/F behaviour, pilot replies, replay and visual design are unchanged. This is a web release; Windows and Android packages were not rebuilt.

## Verification

- Callsign entry and exercise-start tests cover numeric callsigns.
- Parser and offline-recognition grammar tests cover single-aircraft and four-aircraft tactical routing.
- The full simulator and PWA test suites run before publication.
