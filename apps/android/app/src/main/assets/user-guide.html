QGH Simulator

Training use only. Verify all operational procedures against current authorised publications and local instructions.

STARTING AN EXERCISE

  1. Choose Single Aircraft QGH or Tactical QGH. The optional first-run Guided Familiarisation can be skipped or reopened from GUIDED TOUR.
  2. Enter runway orientation, outbound track, inbound / final track, aircraft profile, range, speed and turn rate.
  3. Select Normal QGH or U/S Compass, then start the exercise.
  4. Use D/F transmit, turn, speed, clock and advance controls. Termination opens the recorded flight-path review.

LOCAL VOICE CONTROL

PRESS TO TALK BY DEFAULT

Hold PTT, say one complete command, then release. Open VOICE and select SET UP OFFLINE VOICE before first use. Continuous Listening is optional and shows a compact voice-assistant panel with a clear stop action. Recognition uses the local Vosk engine only; no cloud speech fallback is used. The PWA saves its self-hosted voice model after the user-selected setup step, while Windows and Android include it with the app. If setup or microphone access is unavailable, continue with the normal controls.

NOTES

  • Normal QGH uses assigned-heading turns. U/S Compass uses only left now, right now and stop turn now.
  • D/F bearing is displayed only during a transmission window; QDM is homing and QTE is true bearing.
  • Speed and rate of turn affect manoeuvrability and turn radius. Tactical formation wingmen retain leader speed until separated.
  • The review records the continuous flight path, reference radials, commands and replay cursor. Use the replay-speed control to review efficiently.
